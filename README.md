# CodeInspection

Práctica de laboratorio de Ingeniería de Software II: Inspección de código con PMD.

## Informe

El informe completo de la práctica (capturas del proceso, conjunto de reglas y los dos informes PMD)
está en este repositorio:

**[Informe_CodeInspection_AlejandroTapia.pdf](Informe_CodeInspection_AlejandroTapia.pdf)**

## Contenido del repositorio

- `src/main/java/labcodeinspection/`: código corregido según las reglas de PMD.
- `my_ruleset.xml`: conjunto de reglas PMD usado.
- `pom.xml`: configuración de Maven y del plugin de PMD.
- `reportes/reporte1-antes/pmd.html`: informe PMD antes de corregir (15 violaciones).
- `reportes/reporte2-despues/pmd.html`: informe PMD después de corregir (0 violaciones).
